# RON Hybridation Neuronale

This folder is in the main repository by design.

It defines how RON can coexist with other neuron families without being replaced.

## Families

```text
RON             core movement/causal/conductor family
triaxial_brute  optional X/Y/Z teacher or diagnostic
classical       optional boundary codec
```

## Rule

```text
RON decides.
Hybrid modules enrich, encode, diagnose, or teach.
They do not replace the RON conductor or RONPacket.
```
