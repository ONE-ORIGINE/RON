# RON Pure vs Hybrid

## RON pure

```text
quaternion
motion
energy
cube memory
moments
signatures
Phi-flux
geodesic residual
quaternion symphony
ports
rich synapses
RONPacket
```

## RON triaxial

Adds RON-native TriaxialLens as diagnostic/teacher.

It does not import the classical GRU/attention triaxial neuron into the RON core.

## RON hybrid

Allows external codecs or teachers at the boundary:

```text
text/image/audio codec
triaxial brute teacher
classical adapter
```

but:

```text
RON remains the conductor.
RONPacket remains the official output.
Classical modules do not become the core.
```
